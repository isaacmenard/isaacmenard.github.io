Architecture Flow

01. Ingestion API

Ingest MessagePack events with token validation and rate limits.

->
02. Event Buffer

Normalize payloads and buffer batches safely before export.

->
03. Raw Export

Rotate NDJSON files and upload raw data to S3-compatible buckets.

->
04. ETL Orchestration

Schedule and track Airflow DAG runs from the Elixir service.

->
05. Parquet Layers

Transform events into partitioned parquet and heatmap-ready outputs.

->
06. Dashboard Analytics

Serve SQL-style analytics, heatmaps, and exports for product teams.
